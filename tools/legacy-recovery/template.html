DynastyTrust Legacy Recovery

All you need is your key. Recovers a vault's descriptor from a single key's own on-chain publication. Works fully offline -- nothing on this page ever sends data anywhere.

This tool runs entirely in your browser. Close it and clear your browser history/cache afterward if this computer isn't yours to keep. Never enter a seed phrase into any page unless you understand what it does -- this page's full source is visible via "View Source" if you want to verify it before use.
No vault ID, no shares to combine, no number to remember -- this key's own on-chain address IS the lookup, and it's the SAME single address for every vault this key ever publishes Legacy Recovery for. You'll need the OP_RETURN transaction's full scriptPubKey hex, found on any block explorer by searching the address from your recovery note (most explorers show this on the transaction's output details, sometimes labeled "Script pubkey (hex)" or similar). Paste it below and this tool decodes it, then shows you the exact message to sign -- built from the nonce already published right there, nothing memorized or transcribed. Sign it with the SAME key, at derivation path m/84'/<coin>'/900000'/1/0 -- an ordinary standard-shaped account path (not a custom one), using the CLASSIC message-signing method (plain ECDSA) -- not BIP-322 or a Taproot-address signature, those use a different scheme and will not match. Most hardware wallets' "Sign Message" feature accepts this path directly, the same as signing for any normal account.
