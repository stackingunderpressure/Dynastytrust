DynastyTrust Legacy Recovery

All you need is your key. Recovers a vault's descriptor from a single key's own on-chain publication. Works fully offline -- nothing on this page ever sends data anywhere.

This tool runs entirely in your browser. Close it and clear your browser history/cache afterward if this computer isn't yours to keep. Never enter a seed phrase into any page unless you understand what it does -- this page's full source is visible via "View Source" if you want to verify it before use.
No vault ID, no shares to combine -- this key's own on-chain address IS the lookup. You'll need the OP_RETURN transaction's full scriptPubKey hex, found on any block explorer by searching the address from your recovery note (most explorers show this on the transaction's output details, sometimes labeled "Script pubkey (hex)" or similar). Then sign the exact message below with the SAME key, at derivation path m/9999'/<coin>'/<vault index>'/1', using the CLASSIC message-signing method (plain ECDSA) -- not BIP-322 or a Taproot-address signature, those use a different scheme and will not match. Most hardware wallets' "Sign Message" feature supports signing against a custom derivation path directly.
